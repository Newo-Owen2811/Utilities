# TextDuplicator

A simple Python tool that duplicates user text input multiple times.

## Features

- **No Space**: Repeats your text back-to-back with no gaps.

- **With Space**: Repeats your text with a space between each word.

- **Numbered List**: Adds a list number in front of each repeated line.

- **Custom Separator**: Lets you put your own custom character (like a comma or a dash) between the text.

- **Line Break**: Prints each repeated word on a brand new line.
